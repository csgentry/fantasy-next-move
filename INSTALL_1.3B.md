# Install the complete FantasyNextMove 1.3B project

This is a complete replacement package. Do not manually pick individual files.

## Mac one-step replacement

1. Make sure GitHub Desktop shows no accidental or unfinished local changes.
2. Double-click `INSTALL_COMPLETE_PROJECT.command` inside the extracted package.
3. Choose the existing `fantasy-next-move` repository folder when prompted.
4. The installer verifies the folder is the correct Git repository, preserves `.git`, and replaces the complete project contents.
5. Return to GitHub Desktop, review the changes, paste the included Summary and Description, commit to `main`, and push origin.

The installer refuses to run when the selected repository has uncommitted changes or does not point to `csgentry/fantasy-next-move`.
