# FantasyNextMove 1.3A access and presentation release

This release tightens the beta experience before the deeper Power Rankings and Trade Lab rebuilds.

## Included

- Sidebar order: Dashboard, Trade Lab, Record Book, My Leagues, Connect League
- Dashboard analysis locked to the connected user's roster
- Personalized Priority Board no longer available for other league managers
- All league teams displayed in Power Rankings
- Power Ranking rows changed to read-only league context
- Yahoo connection disabled and labeled Coming Soon until Fantasy Sports API approval is complete

## Next release

Release 1.3B will rebuild the Power Rankings engine with stronger roster, lineup, depth, expected-win, luck, contender, and dynasty analysis.
